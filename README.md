# Ben Rubens · Jazz Bass

Personal website for Ben Rubens, jazz bassist (New Jersey / New York City).

## Edit the content
All text, dates, photos, the "Played with" wall and the gallery live in the `SITE` object
near the bottom of `index.html`. Change the values there and commit.

## Add photos or videos
Put image files in an `images/` folder and reference them as `images/your-photo.jpg`.
Keep videos on YouTube or Vimeo and link them in the `gallery` list.

## Hosting
Served with GitHub Pages from the `main` branch, root folder.
